# Build 34652: integrated client adapters

This increment integrates account-scoped preferences, native client-interface and
device controls, local chat pins, navigation/backgrounds, visual effects, history
migration/read-date tracking, plugin services, feed and bounded classic rendering.
See each `*_PORT.md` for evidence and scope. Catalogue routes do not certify full
original behavior or original pixels. Other-user custom-message style delivery
is still absent; its gate must not be called implemented without that source.

The posts feed merges paginated histories of locally synchronized subscribed
channels, renders text and attachment actions, and opens the original message for
media. It does not claim the original feed's full inline media/interaction parity.
Classic rendering reuses legacy tab/items, conventional plates and composer
geometry; this is not a bit-identical historical Telegram shell.

Local pins passed 48 policy/store and 40 runtime/list checks, including the actual
chat-list consumer closure's update/filter tuple. Local Foundation checks also
cover invalid JSON/property-list values, account isolation and process restart.
Fixture checks remain distinct from the Apple SDK build below.
